# libqxt-for qt5 or qt6
This repository ports [libqxt](https://bitbucket.org/libqxt/libqxt/src/master/) to compile libqxt with Qt5 or Qt6 using cmake.

We currently support: QxtCore, QxtGui  
Future support for: QxtSql, QxtNetwork planned however since I don't use these in my own code it may be a while. **Pull requests are welcome!!**
